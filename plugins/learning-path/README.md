# Learning Paths

A bundled optional Core plugin adapted from [kerr-mwv/learning-path-plugin](https://github.com/kerr-mwv/learning-path-plugin). See UPSTREAM.md and LICENSE for provenance.

Open Learning Paths to build a source-grounded path and start teaching or practice chats for its nodes. The Architect automatically sees the selected course library; optional uploads remain plugin-owned. Native sessions use the same course and the standard composer handoff. Only explicitly linked sessions receive Learning Path tools; the plugin adds no global teacher instructions. Path changes and progress stay in plugin-owned records, with learner-controlled advisory pivots.

Enable or disable it in Settings > Core plugins. Creating/opening a path does not start a model request; explicit Send or starting a child study chat initiates work through the existing connection.
