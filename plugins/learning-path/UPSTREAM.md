# Learning Paths source provenance

Adapted from kerr-mwv/learning-path-plugin, commit e6c150d72b248c7764f704b374611155e21b11a5 (AGPL-3.0-only). The upstream LICENSE, framework and original README are retained.

This bundled version uses the host-selected course library and host-owned native session handoff. It removes global native teaching instructions, fences Architect conversation ownership, and refuses aliased storage ancestors. No new runtime dependencies, community-plugin enablement, account transport or network permissions are introduced. Build tooling and type-only SDK come from the containing LearnHarness checkout.
